# ENTSO-E Realtime Dashboard

Standalone Streamlit dashboard for the public ENTSO-E snapshot data collected by:

https://github.com/Energy-Data-Science/entsoe-realtime-data

The app reads CSV snapshots from the repository's `data` branch and does not need an ENTSO-E API key.

## Streamlit Community Cloud

Use these settings:

```text
Repository: XiaoyuJIN97/entsoe-realtime-dashboard
Branch: main
Main file path: app.py
Secrets: empty
```
